A Redis lock (SET NX PX + token) ensures only one instance runs the critical section at a time — the correct fix for Lost Update.

Dùng Redis lock (SET NX PX + token) để đảm bảo chỉ một instance chạy critical section tại một thời điểm — cách khắc phục đúng cho Lost Update.
